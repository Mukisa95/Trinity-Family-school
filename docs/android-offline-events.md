# Android 1.24: offline calendar, event widgets and reminders

Calendar/event access follows the existing Events calendar/list permission. Android prepares the original `/events` page and its assets, exports the account/family-scoped canonical event cache and existing legacy exam-event projection into the encrypted native snapshot, and keeps the packaged fallback reader usable. Events-only staff grants work without timetable access. Parent school-wide grants are unchanged.

The original calendar query retains saved data, pauses server event reads when either Android or WebView is offline, and reacts to native connection changes. Editing/dragging stays unavailable offline. Reconnection reconciles the existing revision-scoped cache. Native event projection excludes attendee lists, authors and attachment metadata. Native and web validators reject unauthorized datasets; existing account and seven-day lease boundaries remain.

The existing timetable and progress widgets now include Events. `Show all upcoming events` enables the chronological event feed; when off, an event still appears from school-local midnight on the day before its start through its end. All-day end dates include that entire date. Ongoing and tomorrow cards come before timetable rows. Cancelled, completed, draft, rejected and unapproved events do not produce widget cards or reminders. Recurring occurrences reuse the actual saved event instances rather than inventing extra occurrences.

`Widgets & reminders` on the calendar opens native settings. The global event reminder switch enables reminders one calendar day before and at the start, respecting an event's `sendReminders` flag and Android notification permission/channel choices. It remains separate from lesson subscriptions and each widget's display switch. Alarms use the existing accurate-timing permission, reboot/package/time-change receivers and periodic recovery. Delivery rechecks account, lease, current event identity/times/status, duplicate delivery and a 15-minute late limit; removed or cancelled events invalidate posted reminders. Notification tapping and widget event tapping open Events, including its saved offline route.

Older native versions do not receive unsupported datasets: Android 1.24 advertises `X-Trinity-Offline-Features: events` during authenticated session preparation. The endpoint retains the original grant shape for older APKs. Trinity Ganda's published native artifact is retained.

The combined release also includes the pending offline-download banner and Firebase startup-restoration fixes described in `android-offline-banner-session-followup.md`, preserving the latest operations recovery/snapshot scheduler changes already on main.
