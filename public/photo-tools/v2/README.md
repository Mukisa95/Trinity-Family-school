# Passport portrait tools, version 2

This version adds optional person/background segmentation and uses the person
silhouette above a single face to estimate the crown. Automatic framing targets
72% of the square for the head, 9% above the crown, and 19% below the chin for
upper shoulders, subject to source bounds and the minimum 500-pixel source crop.
The output remains a 500 x 500 JPEG, at most 180 KiB of binary data. This is the
school application's passport-style portrait, with its existing square format.

`selfie-segmenter.tflite` is Google's SelfieSegmenter square model, float16,
version **1**, downloaded unmodified from:
https://storage.googleapis.com/mediapipe-models/image_segmenter/selfie_segmenter/float16/1/selfie_segmenter.tflite

Size: **249,537 bytes**. SHA-256:
`191AC9529AE506EE0BEEFA6B2C945A172DAB9D07D1E802A290A4E4038226658B`

Model documentation and Apache 2.0 licensing:
https://storage.googleapis.com/mediapipe-assets/Model%20Card%20MediaPipe%20Selfie%20Segmentation.pdf
See `../v1/LICENSE`. The existing unmodified v1 MediaPipe 1.0.1 runtime, WASM,
and face detector are reused. No duplicate 11 MB runtime download is needed.

`photo-worker.js` is generated by `node scripts/build-photo-tools.cjs`. Its v2 URL
keeps previously cached v1 workers intact. Both versions use the preserved
`trinity-photo-tools-v1` public-assets cache, keyed by immutable asset URLs.
The service worker recognises both directories. Future worker/model changes
must use a new versioned URL; never overwrite published worker/model files.

The background model downloads once when crown estimation or background removal
first needs it. After successful caching, a fresh worker can load it offline.
Pupil photos stay on the device during these operations and are never placed in
the tools cache or uploaded to an external processing service. Ordinary pupil
record saving still follows the existing application's upload requirements.

The optional Remove background control composites a feathered person silhouette
over white, because JPEG cannot store transparency. Adjustments reuse the mask
for the same source/crop and always start from original pixels. Original comparison
includes the original background. A failed removal disables saving until retry
or switching it off; normal cropping/enhancement can continue without the model.
Hair and fine edges should be inspected in Review before saving. Original saved
photos are not changed automatically. One idle worker is retained for two minutes.
