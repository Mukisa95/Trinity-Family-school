# Trinity Family School Management System

A Next.js school management application for Trinity Family School. The system supports day-to-day school operations including pupil records, fees, attendance, exams, parent views, notifications, SMS, banking, inventory, procurement, staff, reports, and Android app support through Capacitor.

## Tech Stack

- Next.js 15
- React 18
- TypeScript
- Tailwind CSS
- Firebase Authentication, Firestore, Storage, Hosting, and Functions
- Capacitor Android
- Firebase Cloud Messaging and web push notifications
- Genkit
- React Query
- React PDF, jsPDF, and related PDF/reporting utilities

## Getting Started

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

The default development server runs on:

```text
http://localhost:9004
```

You can also run the app on port 3000:

```bash
npm run dev3000
```

## Environment Variables

Create a local environment file from the example:

```bash
copy env.example .env.local
```

Then fill in the Firebase, VAPID, SchoolPay, and other private values required by the app.

Important:

- Do not commit real API keys, passwords, private VAPID keys, or service credentials.
- Client-side Firebase values use the `NEXT_PUBLIC_` prefix.
- Server-side values such as SchoolPay credentials and private VAPID keys must stay private.

The Capacitor Android project is stored in:

```text

```

Useful commands:

```bash
npm run cap:sync
npm run cap:sync:android
npm run cap:open:android
npm run cap:build:android
npm run cap:build:release
npm run cap:run:android
```

Use these after installing dependencies and configuring the app.

## Project Structure

```text
src/app          Next.js routes, layouts, pages, and API routes
src/components   Reusable UI and feature components
src/lib          Services, Firebase logic, hooks, constants, and utilities
src/context      Shared React context providers
src/hooks        Reusable React hooks
src/scripts      Data migration, setup, cleanup, and maintenance scripts
src/types        Shared TypeScript types
public           Static files, icons, images, fonts, manifest, and service worker
android          Capacitor Android project
functions        Firebase Functions project
scripts          Build and icon generation helper scripts
```

## Main App Areas

The app includes modules for:

- Pupils and pupil history
- Fees, fee assignments, discounts, collections, and family fee views
- Attendance and excluded days
- Exams, results, reports, PLE results, and certificates
- Parent dashboard and parent-facing pupil information
- Staff, users, access levels, and permissions
- Banking and SchoolPay integration
- Bulk SMS and notifications
- Requirements and requirement tracking
- Inventory, uniforms, and uniform tracking
- Procurement
- Duty and service management
- Events and timetable
- Settings, school profile, and administration tools

## Data and Maintenance Scripts

The project contains maintenance scripts under:

```text
src/scripts/
```

These scripts handle tasks such as migrations, account creation, SMS setup, access-level initialization, pupil data repair, academic year cleanup, and Firebase-related fixes.

Run them carefully. Many scripts can update live Firebase data.

## Notes

- `node_modules/` is not committed and must be restored with `npm install`.
- `.next/` is generated by Next.js and can be recreated with `npm run build` or `npm run dev`.
- Real credentials should live only in local environment files or secure deployment settings.
- Run `npm run typecheck` and `npm run build` before deployment when possible.
